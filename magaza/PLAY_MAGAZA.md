## 5. Test → Kapalı test

1. **Test → Kapalı test → Kanal oluştur** (adı: "Kapalı test").
2. **Test kullanıcıları** → "E-posta listesi oluştur" → en az **12 Gmail adresi** ekle.
3. **Yeni sürüm oluştur** → GitHub Actions'taki `altin-hali-play-store-aab` içinden çıkan **AltinHali.aab** dosyasını yükle.
4. Sürüm notu:
```
<tr-TR>
İlk test sürümü: halıyı yıka, altınları bul! Hataları ve önerilerini bize yaz.
</tr-TR>
```
5. Kaydet → İncelemeye gönder. Testçilere gelen katılım bağlantısını paylaş.
6. **14 gün** boyunca 12 testçi oyunu yüklü tutsun → ardından **Üretim** erişimi için başvur.

> İlk yüklemede **Play App Signing**'i kabul et (Google uygulamayı kendi anahtarıyla imzalar; senin anahtarın sadece "yükleme anahtarı" olur).
